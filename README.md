# friendship-day-wishes
💙 An interactive Friendship Day Wishes website built with HTML, CSS, and JavaScript. Features a personalized login, Best Friend List celebration, confetti, falling hearts, smooth animations, and a responsive modern UI. 🤝✨
Celebrate Friendship Day with a beautiful and interactive website!

## ✨ Features

- 🔐 Personalized Login Page
- 👤 Enter Your Name
- 🎉 Congratulations Animation
- ❤️ Best Friend List Message
- 💌 Personalized Friendship Day Wishes
- 🎊 Confetti Celebration
- 💖 Falling Hearts Animation
- ✨ Smooth Animations & Glassmorphism UI
- 📱 Fully Responsive Design
- 🌈 Modern Gradient Background
- 💙 Wishes from Hemanth Adapa

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas Confetti

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Enter your name.
4. Enjoy the Friendship Day celebration!
